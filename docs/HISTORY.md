- **2026-09-05** — S2.1 done and verified: the audio streaming endpoint. Range requests are not a nicety here — without them a listener cannot seek, a browser will not scrub, and iOS refuses to play at all — so the endpoint supports single ranges, open-ended ranges, suffix ranges, `HEAD`, `ETag`/`If-None-Match`, `If-Modified-Since` and `If-Range`. The chapter ID in the URL is treated as a question, never an answer: it is resolved to a real chapter, the chapter to its book, and the book is what access is checked against. A refusal is a 404, indistinguishable from a chapter that never existed, because telling a stranger which IDs are real and merely forbidden is an invitation to enumerate the library. The stored file path is re-checked against the uploads directory too: a path from the database is only as trustworthy as whatever wrote it.
