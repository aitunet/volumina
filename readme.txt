Publish audiobooks on WordPress with a real listening experience: chapters, remembered position, speed and a sleep timer.

== Description ==

Volumina turns WordPress into an audiobook library. A book holds its chapters in
order, and the player remembers where each listener stopped, so a nine-hour book
can be finished across a week of commutes.

Built for the phone first, because that is where people listen.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/volumina` or install it from the
   plugin directory.
2. Activate it through the Plugins screen.
3. Add your first audiobook under Audiobooks.

== Frequently Asked Questions ==

= Does it protect my files from being downloaded? =

No, and no plugin honestly can. Browser audio is served to the browser. Volumina
serves files normally.
